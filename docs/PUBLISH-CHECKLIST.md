# 🚀 چک‌لیست انتشار افزونه در Chrome Web Store + اتصال به وردپرس

> هدف: کاربر بنر سایت شما را کلیک کند → ۲ کلیک → افزونه نصب و بدون هیچ کلیدی کار کند.

---

## معماری (چرا بدون کلید در افزونه؟)

```
افزونه کاربر ──► سرور شما POST /api/ext/chat ──► AvalAI (کلید شما، رمزنگاری‌شده روی سرور)
                        │
                        ├─ Rate limit هر IP: ۶/دقیقه، ۴۰/ساعت
                        ├─ سقف روزانهٔ کل: ۶۰۰ درخواست (قابل تغییر در .env)
                        └─ فقط رفتار دستیار خرید (نمی‌شود از آن به‌عنوان API آزاد استفاده کرد)
```

**قانون طلایی:** هر چیزی داخل بستهٔ افزونه باشد قابل استخراج است. کلید فقط روی سرور شماست.

---

## گام ۱ — دپلوی سرور (پنل مدیریت)

```bash
# روی VPS/سرور خودتان:
cd admin-panel
pip3 install -r requirements.txt
cp .env.example .env
nano .env
#   ADMIN_PASSWORD=یک رمز قوی
#   AVALAI_API_KEY=کلید AvalAI شما (aa-...)
#   AVALAI_MODEL=qwen3.8-flash
#   EXT_DAILY_LIMIT=600        ← سقف هزینهٔ روزانهٔ خودتان
python3 run.py                # یا systemd/docker
```

HTTPS الزامی است (مثلاً Nginx + Let's Encrypt). بعد در `.env` بگذارید `COOKIE_SECURE=true`.

### 🔄 تعویض کلید (الان انجام دهید)
کلیدی که در چت فرستاده‌اید، لو رفته محسوب می‌شود. از [پنل AvalAI](https://chat.avalai.ir/platform/home) یک کلید **جدید** بسازید و فقط در `.env` سرور بگذارید.

## گام ۲ — اتصال افزونه به سرور (دو خط!)

1. `smart-shopping-assistant/lib/constants.js`:
   ```js
   export const SERVICE_BASE_URL = 'https://پنل-شما.example.com';
   ```
2. `smart-shopping-assistant/manifest.json`:
   ```json
   "host_permissions": [
     "https://api.telegram.org/*",
     "https://پنل-شما.example.com/*"
   ]
   ```
   (خط `http://localhost:8000/*` را حذف کنید.)

3. تست لوکال: پنل را بالا بیاورید، افزونه را در `chrome://extensions` → Reload، چت را امتحان کنید.

## گام ۴ — ثبت در Chrome Web Store

1. [Developer Dashboard](https://chrome.google.com/webstore/devconsole) → ثبت‌نام (۵ دلار یک‌بار)
2. **New item** → ZIP بالا را آپلود کنید
3. **Store listing** (متن پیشنهادی پایین همین فایل)
4. **Privacy**:
   - Single purpose: `دستیار خرید هوشمند مبتنی بر هوش مصنوعی`
   - Permission justifications:
     - `history` → «تحلیل محلی سلیقهٔ خرید کاربر با رضایت صریح؛ فقط نام دامنه و تعداد بازدید، بدون URL و عنوان»
     - `cookies` → «فقط نام و دامنهٔ کوکی‌های بی‌خطر برای غنی‌سازی تحلیل؛ مقادیر کوکی هرگز خوانده/ذخیره/ارسال نمی‌شوند؛ با رضایت صریح کاربر»
     - host permissions → «ارتباط با سرور سرویس دستیار و تلگرام برای ارسال اختیاری خروجی»
   - Remote code: استفاده نمی‌شود ✅
   - Data usage: تیک‌های جمع‌آوری داده را صادقانه پر کنید (Browsing activity → collected, NOT sold, NOT unrelated purposes)
   - لینک Privacy Policy (بخش ۶ این فایل)
5. Submit for review → معمولاً چند ساعت تا چند روز

## متن پیشنهادی Store Listing (فارسی)

**عنوان:** خریدار پرو — دستیار خرید هوشمند
**خلاصه (۱۳۲ کاراکتر):** دستیار خرید فارسی با هوش مصنوعی: سلیقهٔ شما را می‌فهمد، محصولات مناسب را پیشنهاد می‌دهد و در فروشگاه‌های معتبر جستجو می‌کند.

**توضیحات:**
🛍️ خریدار پرو، دستیار خرید هوشمند شماست:
• تحلیل خودکار سلیقه بر اساس مرور اخیر شما — کاملاً محلی و پاکسازی‌شده
• گفتگوی صمیمی فارسی و پیشنهاد محصولات مناسب
• جستجوی یک‌کلیکی در دیجی‌کالا، ترب، باسلام، تکنولایف، آمازون و…
• خروجی اختیاری به ربات تلگرام شما

🛡️ حریم خصوصی — شفاف و قابل راستی‌آزمایی:
• هیچ مقدار کوکی (رمز/نشست) خوانده، ذخیره یا ارسال نمی‌شود
• دامنه‌های بانکی، پیام‌رسان، ایمیل و محتوای بزرگسال به‌کلی حذف می‌شوند
• فقط نام دامنه + تعداد بازدید نگه‌داری می‌شود؛ بدون URL و عنوان صفحات
• داده‌ها روی سیستم خودتان می‌ماند؛ ارسال به تلگرام فقط با اقدام شما

## گام ۶ — Privacy Policy (متن آماده)

صفحه‌ای در وردپرس (مثلاً `/privacy/kharidar-pro`) با این محتوا بسازید:

> **سیاست حریم خصوصی افزونه «خریدار پرو»**
>
> چه داده‌هایی پردازش می‌شود؟ تاریخچهٔ مرور شما (فقط نام دامنه و تعداد بازدید)، عبارت‌های جستجو (پس از حذف عبارات نامناسب و ادغام تکراری‌ها) و نام دامنهٔ کوکی‌های بی‌خطر. **مقادیر کوکی، رمزها و نشست‌های ورود هرگز خوانده نمی‌شوند.** صفحات بانکی، پیام‌رسان‌ها، ایمیل و محتوای بزرگسال به‌کلی از تحلیل حذف می‌شوند.
>
> داده کجا ذخیره می‌شود؟ روی مرورگر خود شما. ارسال خروجی به ربات تلگرام فقط با اقدام صریح شما انجام می‌شود.
>
> هوش مصنوعی: برای تولید پاسخ، پیام شما و آمار خلاصهٔ رفتار (دامنه‌ها و جستجوهای پرتکرار) به سرور سرویس ما و از آن‌ها به سرویس AvalAI ارسال می‌شود. هیچ داده‌ای فروخته یا برای تبلیغات استفاده نمی‌شود.
>
> حذف داده: از تنظیمات افزونه، «حذف کامل داده‌ها» همه‌چیز را پاک می‌کند.
