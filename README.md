# 🛒 خریدار پرو — دستیار خرید هوشمند + داشبورد تحلیل پروفایل

مجموعه‌ای دو بخشی برای تحلیل امنِ رفتار مرور کاربران و دستیار خرید مبتنی بر هوش مصنوعی:

| بخش | توضیح |
|---|---|
| 🧩 **افزونه کروم** (`smart-shopping-assistant/`) | جمع‌آوری «پاکسازی‌شده» تاریخچه مرور + چت خرید با AvalAI + خروجی امن |
| 📊 **داشبورد تحلیل** (`dashboard/`) | بانک اطلاعاتی پروفایل‌ها (شبیه مخاطبین گوشی) + تحلیل هوش مصنوعی + خروجی ZIP/تلگرام |

---

## 🛡️ معماری حریم خصوصی (مهم‌ترین بخش)

داده خام (کوکی کامل و رکورد خام تاریخچه) **فقط در حافظه لحظه‌ای** پردازش می‌شود و خروجی از **۶ لایه فیلتر** عبور می‌کند:

```
کوکی خام ──► ❶ حذف HttpOnly (نشست‌های لاگین)
             ❷ حذف دامنه حساس (پیام‌رسان/بانک/جنسی/ایمیل/هویت)
             ❸ حذف نام کوکی حساس (session/token/auth/card/…)
             ❹ ساخت WHITELIST: فقط {domain, name} — مقدار هرگز کپی نمی‌شود
             ❺ حذف تکراری‌ها
             ❻ اسکراب نهایی ضد نشتی (JWT/کارت/شبا/ایمیل/Base64)
تاریخچه خام ► فقط دامنه + تعداد بازدید (بدون URL، بدون عنوان صفحه)
              + همان فیلتر دامنه‌های حساس
جستجوها ────► نرمال‌سازی فارسی/عربی → حذف مستهجن → ادغام تکراری دقیق
              («خرید کفش»=«خرید کفش» ولی «خرید کفش ورزشی» حفظ می‌شود)
```

**تضمین‌های قابل تست** (تست‌های واحد در `tests/sanitize.test.js` — ۴۴ تست):
- مقدار کوکی در هیچ شیء خروجی حتی ساخته نمی‌شود (whitelist نه blacklist)
- دامنه‌های حساس حتی «نامشان» هم در خروجی نمی‌آید
- جستجوی مستهجن فقط شمارش می‌شود و محتوایش هیچ‌جا نمی‌ماند

### رازها
- کلید AvalAI، توکن ربات تلگرام و شناسه ادمین با **AES-256-GCM** (کلید از PBKDF2-SHA256 با ۳۱۰هزار تکرار) رمز می‌شوند.
- کلید رمزنگاری فقط در `chrome.storage.session` کش می‌شود (با بستن مرورگر پاک می‌شود).
- لاگر داخلی (`lib/log.js`) هر رزمشرهمانند (توکن/کلید/کارت/ایمیل) را قبل از چاپ پاک می‌کند.
- داشبورد هم قفل اختیاری دارد: کل بانک پروفایل‌ها رمزنگاری می‌شود.

## 🚀 نصب و راه‌اندازی

### افزونه کروم
1. `chrome://extensions` → **Developer mode** را روشن کنید
2. **Load unpacked** → پوشه `smart-shopping-assistant` را انتخاب کنید
3. آیکون افزونه → تیک پذیرش → «پیکربندی امن»:
   - **رمز رمزنگاری** (حداقل ۶ کاراکتر) — برای رمز شدن رازها
   - **کلید API AvalAI** از [داشبورد AvalAI](https://chat.avalai.ir/platform/home)
   - (اختیاری) توکن ربات تلگرام + شناسه عددی ادمین

### داشبورد
- روش ۱: فایل `dashboard/index.html` را در مرورگر باز کنید (دابل‌کلیک؛ بدون نیاز به سرور)
- روش ۲: `python3 -m http.server` در ریشه پروژه → `http://localhost:8000/dashboard/`
- فایل‌های خروجی افزونه (⚙️ ← داده و حریم خصوصی ← دانلود JSON) را با کشیدن و رها کردن اضافه کنید

## 🤖 اتصال به AvalAI

طبق [مستندات رسمی](https://docs.avalai.org/fa/): رابط **سازگار با OpenAI**

- **Base URL:** `https://api.avalai.ir/v1`
- **احراز هویت:** هدر `Authorization: Bearer <KEY>`
- **نقطه پایان:** `POST /v1/chat/completions`
- **مدل‌های پیشنهادی:** `qwen3.8-flash` و `glm-5.3-flash` برای مصرف کم توکن (دسته‌بندی/تحلیل سبک)، `gpt-6-astra` برای تحلیل نهایی عمیق

هر دو بخش (افزونه و داشبورد) از همین یک متد استفاده می‌کنند؛ پیاده‌سازی افزونه در `lib/ai.js` و داشبورد در تابع `avalaiChat` داخل `dashboard.js`.

### مصرف بهینه توکن (طبق درخواست)
- دسته‌بندی اولیه دامنه‌ها **بدون AI** و با دیکشنری محلی انجام می‌شود (صفر توکن)
- تحلیل AI فقط روی خلاصه آماری (حداکثر ۴۰ دامنه + ۵۰ جستجو) اجرا می‌شود
- خروجی تحلیل با اسکیمای JSON ساختاریافته گرفته می‌شود و **برای همیشه** در پروفایل ذخیره می‌ماند

## 📊 داشبورد — گردش کار

```
افزودن کاربر (فایل JSON) ──► کارت پروفایل (U-0001، U-0002، …)
        │
        ▼ کلیک روی کارت
صفحه پروفایل:
  ├── 🌐 سایت‌های بازدیدشده  ──► دسته‌بندی (فروشگاهی، فیلم، هوش مصنوعی، …)
  │                              + فیلتر دسته + جستجو + نوار بازدید
  ├── 🔎 جستجوها            ──► همان دسته‌بندی + تعداد تکرار
  ├── ❤️ علاقه‌مندی‌ها       ──► موتور محلی: پرتکرارترین جستجو، پربازدیدترین
  │                              سایت، دسته‌های محبوب، وفاداری به فروشگاه،
  │                              الگوی زمانی، دامنه کاوش
  └── ✨ تحلیل هوش مصنوعی   ──► با یک کلیک: عنوان، علاقه‌مندی‌ها، شخصیت،
                                 عادت خرید، پیش‌بینی نیاز، نکات بازاریابی
                                 (دائمی ذخیره می‌شود)
```

امکانات تکمیلی: جستجو/مرتب‌سازی پروفایل‌ها، تغییر نام، خروجی JSON و ZIP (بدون وابستگی)، ارسال پروفایل به ربات تلگرام، قفل رمزنگاری کل بانک، رابط کاملاً فارسی RTL.

├── index.html
├── dashboard.css
└── dashboard.js              Store + رمزنگاری + AI + تلگرام + ZIP دست‌ساز

tests/sanitize.test.js        ۴۴ تست واحد حریم خصوصی

## ⚠️ نکات امنیتی مهم (اقدام قبلی)

1. **کلید Gemini قدیمی** که در نسخه ۱ به‌صورت هاردکد بود، لو رفته است — در Google AI Studio باطلش کنید.

3. توکن ربات تلگرام را فقط از پنل تنظیمات وارد کنید — در کد کامیت **نمی‌شود** و رمزنگاری ذخیره می‌شود.
