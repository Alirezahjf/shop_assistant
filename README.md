# 🛒 خریدار پرو — دستیار خرید هوشمند + پنل مدیریت پروفایل‌ها

سیستم دو-بخشی با معماری امن:

```
┌──────────────────┐         ┌──────────────────┐         ┌─────────────────────┐
│  🧩 افزونه کروم   │  فایل   │  📨 ربات تلگرام   │  واکشی  │ 🖥️ پنل مدیریت (FastAPI)│
│  (سمت کاربر)     │ ──────► │  کانال انتقال     │ ──────► │  (سمت مدیر — وب)     │
│  جمع‌آوری پاک     │  JSON   │  فقط چت ادمین     │  API    │  تحلیل + بانک پروفایل│
└──────────────────┘         └──────────────────┘         └─────────────────────┘
```

| بخش | مخاطب | تکنولوژی | محل |
|---|---|---|---|
| **افزونه کروم** | کاربر نهایی | JS (MV3) — جمع‌آوری پاکسازی‌شده + چت AvalAI + ارسال به ربات | `smart-shopping-assistant/` |
| **پنل مدیریت** | فقط مدیر/سازنده | **Python + FastAPI** + SQLite — وب‌اپ مستقل با ورود رمز | `admin-panel/` |

> پنل مدیریت به‌هیچ‌وجه داخل افزونه قرار ندارد؛ یک سرویس وب جداگانه است که مدیر روی سرور اجرا می‌کند.

## 🛡️ معماری حریم خصوصی (مشترک و چندلایه)

داده خام (کوکی کامل/رکورد خام تاریخچه) فقط در حافظه لحظه‌ای پردازش می‌شود:

```
کوکی خام ──► ❶ حذف HttpOnly (نشست‌های لاگین)
             ❷ حذف دامنه حساس (پیام‌رسان/بانک/جنسی/ایمیل/هویت)
             ❸ حذف نام کوکی حساس (session/token/auth/card/…)
             ❹ ساخت WHITELIST: فقط {domain, name} — مقدار هرگز کپی نمی‌شود
             ❺ حذف تکراری‌ها
             ❻ اسکراب نهایی ضد نشتی (JWT/کارت/شبا/ایمیل/Base64)
تاریخچه خام ► فقط دامنه + تعداد بازدید (بدون URL، بدون عنوان صفحه)
جستجوها ────► نرمال‌سازی فارسی/عربی → حذف مستهجن → ادغام تکراری دقیق
              («خرید کفش» = «خرید کفش» ولی «خرید کفش ورزشی» حفظ می‌شود)
```

### اعتبارسنجی مجدد سمت سرور (دفاع در عمق)
پنل مدیریت **هرگز به فایل ورودی اعتماد نمی‌کند**: هر فایلِ دریافتی (از تلگرام یا آپلود) دوباره با همان قوانین در پایتون بازرسی می‌شود (`admin-panel/app/sanitize.py`):
- فیلدهای غیرمجاز (مثل `value` کوکی!) → کل رکورد حذف
- دامنه‌های حساس دوباره فیلتر می‌شوند (حتی اگر فایل مخرب دستکاری‌شده باشد)
- مستهجن‌ها و تکراری‌ها دوباره پاک می‌شوند
- الگوهای نشتی (JWT/کارت/شبا/ایمیل/Base64) اسکراب نهایی می‌شوند
- فایل تماماً مخرب → **رد کامل با پیام فارسی**

### رازها (نگارش ۲.۲)
- سمت افزونه: کلید AvalAI / توکن ربات / شناسه ادمین با **AES-256-GCM** رمز می‌شوند. کلیدِ رمزنگاری یک **کلید تصادفی per-install («کلید دستگاه»)** است که در `chrome.storage.local` نگه داشته می‌شود — یعنی **کاربر لازم نیست هیچ رمزی بسازد یا وارد کند**. قفلِ مبتنی بر رمز عبور (PBKDF2 با ۳۱۰٬۰۰۰ تکرار) یک قابلیت **پیشرفته و اختیاری** است و هرگز مسیر اصلی را مسدود نمی‌کند. لاگر داخلی هر راز را قبل از چاپ پاک می‌کند.
- سمت پنل: رازها با **Fernet** در SQLite رمز می‌شوند (کلید از `SECRET_KEY`)؛ هرگز plaintext و هرگز در لاگ نیستند. توکن فقط در هدر درخواست به تلگرام می‌رود.

> ⚠️ **هشدار صریح:** مستندات AvalAI می‌گوید کلید API را در فرانت‌اند قرار ندهید. کلیدی که داخل بستهٔ افزونه منتشر شود (از طریق `lib/owner-config.js`) برای هر نصب‌کننده‌ای قابل استخراج است. برای انتشار عمومی، **`avalaiApiKey` را خالی بگذارید** تا گفتگو از پروکسی پنل انجام شود. جزئیات: [`docs/PUBLISH-CHECKLIST.md`](docs/PUBLISH-CHECKLIST.md).

## 🚀 راه‌اندازی

### ۱) افزونه کروم (سمت کاربر)
1. `chrome://extensions` → Developer mode → **Load unpacked** → پوشه `smart-shopping-assistant`
2. آیکون افزونه → تیک «می‌پذیرم» → **«موافقم و ادامه»**
3. فقط **برچسب دستگاه** و **بازهٔ تحلیل** را انتخاب کنید (کلیدها/توکن‌ها خودکار از پیکربندیِ مالک رمزنگاری می‌شوند)
4. **لودینگ مرحله‌ایِ استخراج** (خواندن تاریخچه → پاکسازی حساس → دسته‌بندی محلی → ساخت اسنپ‌شات → ارسال به ربات) → ورود به گفتگو
5. خروجیِ پاکسازی‌شده **به‌طور خودکار** به ربات تلگرامِ شما فرستاده می‌شود

### ۲) پنل مدیریت (سمت مدیر)

```bash
cd admin-panel
pip3 install -r requirements.txt
cp .env.example .env        # ⚠️ ADMIN_PASSWORD را تغییر دهید
python3 run.py              # → http://0.0.0.0:8000  (ورود: /login)
```

اولین ورود: رمز از `ADMIN_PASSWORD` در `.env` (پیش‌فرض `admin1234` — فوراً عوضش کنید؛ از ⚙️ تنظیمات ← «تغییر رمز مدیر»).

#### جریان ایمپورت کاربر جدید (همان فایل‌های ربات تلگرام)
1. در ⚙️ تنظیمات پنل، **توکن ربات** و **شناسه عددی چت ادمین** را ذخیره کنید (رمز می‌شوند)
2. افزونه‌ی کاربر فایل `browsing-profile_*.json` را به چت ربات می‌فرستد
3. در پنل، **«📨 دریافت از تلگرام»** → سرور از Bot API آپدیت‌ها را می‌گیرد، فقط فایل‌های JSON **از چت ادمین** را دانلود، اعتبارسنجی مجدد و ایمپورت می‌کند (+ پیام تایید به همان چت)
   - ضد ایمپورت تکراری با `file_unique_id` و offset
4. آپلود دستی همان فایل‌ها (drag & drop) هم پشتیبانی می‌شود — مثلاً فایل‌های دانلودی از تلگرام

## 🖥️ پنل مدیریت — امکانات

- **ورود امن**: رمز PBKDF2-310k، نشست کوکی HttpOnly، محدودیت ۵ تلاش ناموفق، تغییر رمز از UI
- **بانک پروفایل‌ها** مثل مخاطبین گوشی: `U-0001، U-0002…` با نام قابل ویرایش، آواتار، آمار، منبع (📨 تلگرام / 📥 آپلود / ✨ نمونه)
- **نمای پروفایل**: KPI + نمودار فعالیت + ۴ باکس:
  - 🌐 **سایت‌های بازدیدشده** → کتگوری‌بندی سرور-محور (فروشگاهی، فیلم و سریال، هوش مصنوعی، …) با فیلتر کتگوری + جستجو + نوار بازدید
  - 🔎 **جستجوها** → همان کتگوری‌بندی با کلیدواژه‌های فارسی (خرید/قیمت/آموزش/فیلم/…) + تعداد تکرار
  - ❤️ **علاقه‌مندی‌ها** → موتور محلی پایتون (صفر توکن): پرتکرارترین جستجو، پربازدیدترین سایت، دسته‌های محبوب، وفاداری به فروشگاه، الگوی زمانی، دامنه کاوش
  - ✨ **تحلیل هوش مصنوعی** → با یک کلیک از طریق AvalAI (سمت سرور، خروجی JSON ساختاریافته) و **ذخیره دائمی** در DB
- **خروجی**: دانلود JSON هر پروفایل، ارسال مجدد به ربات
- **مصرف بهینه توکن**: دسته‌بندی و علاقه‌مندی‌ها کاملاً محلی؛ AI فقط روی خلاصه آماری (≤۴۰ دامنه + ≤۵۰ جستجو) با مدل ارزان `qwen3.8-flash`

## 🤖 AvalAI (طبق docs.avalai.org)
- Base URL: `https://api.avalai.ir/v1` — احراز: `Authorization: Bearer <KEY>` — `POST /v1/chat/completions`
- کلید را از [داشبورد AvalAI](https://chat.avalai.ir/platform/home) بگیرید؛ در پنل از ⚙️ وارد کنید (رمز می‌شود) یا در `.env` بگذارید
- پیاده‌سازی افزونه: `smart-shopping-assistant/lib/ai.js` — پیاده‌سازی پنل: `admin-panel/app/avalai.py`

### 🔑 معماری کلید (v2.1) — کاربر هیچ کلیدی وارد نمی‌کند
```
افزونه کاربر (بدون کلید) ──► سرور شما POST /api/ext/chat ──► AvalAI (کلید شما)
                                  │  rate-limit ۶/دقیقه و ۴۰/ساعت هر IP
                                  │  سقف روزانهٔ کل (EXT_DAILY_LIMIT)
                                  │  پرامپت سیستم سمت سرور (سوءاستفاده به‌عنوان API آزاد ممکن نیست)
                                  └─ فیلتر حساس/مستهجن روی کانتکست ورودی
```
کلید AvalAI **هرگز داخل بستهٔ افزونه قرار نمی‌گیرد** (هر چیزی در افزونه قابل استخراج است)؛ فقط در `.env` سرور. راهنمای انتشار در Web Store + اتصال بنر وردپرس: **`docs/PUBLISH-CHECKLIST.md`**

## 🧪 تست‌ها

```bash
# یک‌باره: وابستگیِ فقط-تست (jsdom برای تست رابط پاپ‌آپ)
npm install

# همهٔ تست‌ها
npm test

# یا جداگانه:
node --test tests/sanitize.test.js     # ۴۴ تست — پاکسازی/نشت‌سنجی
node --test tests/crypto.test.js       # ۱۲ تست — رمزنگاری (رفع باگ exportKey، کلید دستگاه، بازنشانی)
node --test tests/ai-params.test.js    #  ۶ تست — پارامترهای AvalAI مطابق مستندات
node --test tests/popup.test.js        # ۱۰ تست — رابط پاپ‌آپ با jsdom (دکمهٔ مرده، ذخیره، تست‌ها، لودینگ)

# پنل (Python) — ۶۹ تست
cd admin-panel && python3 -m pytest tests/ -q
```

پوشش: فیلتر دامنه‌های حساس، هرگز-ذخیره-نشدن مقدار کوکی، ادغام/تمایز جستجو، مستهجن‌فیلتر، رد فایل مخرب، نشتی‌سنجی، دسته‌بندی، تطبیق جستجوی فارسی، موتور علاقه‌مندی، **رفت‌وبرگشتِ رمزنگاری و بازیابی نصبِ گیرکرده**، **پارامترها و کدهای خطای AvalAI**، و **نبودِ دکمهٔ مرده در رابط پاپ‌آپ**.

> `tests/crypto.test.js` روی کدِ پیش از رفع باگ fail می‌شد (`key is not extractable`)؛ این همان تست رگرسیونِ باگ گزارش‌شده است.

## ⚠️ نکات امنیتی مهم
1. کلید Gemini هاردکدِ نسخه ۱ لو رفته — در Google AI Studio باطلش کنید.
2. سرور `http://5.9.166.254` از نسخه ۱ به‌کلی حذف شد؛ تنها کانال انتقال داده، ربات تلگرامِ خودتان است.
3. توکن ربات را فقط از UI وارد کنید؛ در کد/گیت قرار نمی‌گیرد و رمز ذخیره می‌شود.
4. پنل را روی HTTPS قرار دهید (`COOKIE_SECURE=true` در `.env`) و پشت reverse proxy با احراز هویت IP در صورت امکان.
